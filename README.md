# 맞춤법 문제 도우미

`index.html`을 Chrome에서 열면 됩니다. 설치나 서버는 필요 없습니다.

## 사용 방법

1. **직접 입력**: 문장과 1·2번 선택지를 입력한 뒤 `정답 찾기`를 누릅니다.
2. **캡처 OCR**: `Windows + Shift + S`로 문제 영역을 캡처하고, `캡처 붙여넣기` 탭의 큰 영역을 클릭해 `Ctrl + V`를 누릅니다. OCR 결과는 수정할 수 있습니다.
3. **문제집**: 새 문항을 저장하거나 JSON으로 내보내기/불러오기를 할 수 있습니다. 데이터는 이 브라우저의 LocalStorage에만 보관됩니다.
4. **저장되지 않은 문제**: 직접 입력 탭에서 검색하면 각 선택어를 국립국어원 표준국어대사전에서 확인하는 링크가 표시됩니다. 확인한 정답은 문제집에 저장해 다음부터 바로 찾을 수 있습니다.

## 참고

- OCR은 Tesseract.js와 한국어 언어 데이터를 처음 사용할 때 인터넷 연결이 필요합니다. 이후 브라우저 캐시 상태에 따라 재사용될 수 있습니다.
- 이 도구는 문제를 찾아 보여 주는 수동 보조 도구이며, 게임 화면·입력·프로세스와 연동하지 않습니다.

인터넷에 공개하는 방법은 [DEPLOY-GITHUB-PAGES.md](DEPLOY-GITHUB-PAGES.md)를 참고하세요.
